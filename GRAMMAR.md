# Грамматика и семантика языка .alg

Описание конструкций **School Algol** (файлы `.alg`) для движка SCHOOLALGOL **1.2.0**. Обзор проекта и CLI — в [README.md](README.md).

Язык самостоятельный (не «классический ШАЯ»): `таб`, `использовать`, `словарь`, `запись`, `переч`, операторы `<>` / `>=` / `<=` — часть диалекта `.alg`.

## Пайплайн и диагностика

Перед выполнением и транспиляцией выполняется семантический анализ.

| Флаг | Эффект |
|------|--------|
| `--verbose` | В stderr: этапы (лексер → парсер → семантика → …) и подписи токенов RU/EN |
| `--trace` | Пошаговая трассировка операторов |
| `--warnings-as-errors` | Предупреждения → код выхода 3 |
| `--dump-ast` / `--dump-ast-format text\|json` | Дерево разбора |
| `--repl` / `--repl --lang en` | Интерактивный режим |
| `--transpile` + `--keep-cyrillic` / `--permissive` | Генерация C |
| `--debug-protocol` / `--break N` | SHAYDBG для Step Debug в Eclipse |

## Точка входа

- Процедура без параметров с именем **основнаяпрограмма** или **mainprogram**.
- Имена регистронезависимы (`ОсновнаяПрограмма` = `основнаяпрограмма`, `MainProgram` = `mainprogram`).

## Двуязычные ключевые слова (RU + EN)

Русские и английские формы — **синонимы одного токена**. Парсер различает `TokenType`, не «язык файла». В одном файле допустимо смешение (`if` + `то` + `endif`).

| RU | EN | RU | EN |
|----|-----|----|-----|
| алг | proc | цел | int |
| нач | begin | вещ | real |
| кон | end | лог | bool |
| арг | arg | лит | str |
| рез | res | таб | tab |
| конст | const | файл | file |
| использовать | import | словарь | dict |
| ввод | input | запись | rec |
| вывод | output | переч | enum |
| если | if | да | true |
| то | then | нет | false |
| иначе | else | и | and |
| все | endif | или | or |
| нц | loop | не | not |
| кц | eloop | | |
| для | for | | |
| пока | while | | |
| от | from | | |
| до | to | | |

Пример (EN):

```alg
proc mainprogram
begin
  int x
  x := 1
  if x > 0 then
    output "ok"
  endif
end
```

Каталог: `examples/en/`.

## Модули

- **использовать** / **import** `"файл.alg"` — путь относительно каталога текущего файла.
- Допускаются `..` и абсолютные пути; **sandbox нет**.
- Циклический импорт → ошибка с цепочкой файлов.

## Объявления

- **конст** / **const** *имя* = *выражение*.
- Типы переменных: **цел**/**вещ**/**лит**/**лог**/**файл**/**словарь** (и EN-синонимы), пользовательский тип записи/перечисления.
- Массив: **таб** *тип* *имя*[*нач*:*кон*] — произвольный `нач`; в C учитывается offset.
- **алг** / **proc** *имя* [ ( **арг** … ; **рез** … ) ] [ объявления ] **нач** тело **кон** — процедура или функция (при **рез** — функция). Перед **нач** — только объявления (Pascal-style); в теле после **нач** объявления и операторы могут чередоваться.
- **запись** / **rec** *имя* **нач** поля **кон**.
- **переч** / **enum** *имя* ( *член1* , … ).

## Операторы

- *lvalue* **:=** *выражение* — присваивание (переменная, элемент массива, поле записи, ключ словаря).
- **вывод** / **output** [ *файл* , ] *выражение* … [ : *ширина* [ : *точность* ] ] — консоль или файл.
- **ввод** / **input** [ *файл* , ] *переменная* … — консоль или файл.
  - При EOF в файле в числовую переменную записывается `0.0` (контракт языка).
  - Рекомендуется `конецфайла(f)` / `eof(f)` перед чтением.
- **если** … **то** … [ **иначе** … ] **все** (EN: **if** … **then** … [ **else** … ] **endif**).
- **нц пока** … **кц** / **loop while** … **eloop**.
- **нц для** *перем* **от** *a* **до** *b* … **кц** / **loop for** … **from** … **to** … **eloop** (диапазон включительно).
- Вызов: *имя* ( *аргументы* ).

### Цикл `нц для` и неявное объявление

Если переменная цикла не объявлена, интерпретатор может неявно создать её как **цел** и выдать `ImplicitDeclareWarning`. В учебных программах лучше явно писать `цел i` / `int i`.

## Выражения

- Литералы: числа, строки `"…"`, **да**/**нет** (**true**/**false**).
- Доступ: *выражение*.*поле*, *выражение*[*индекс*].
- Унарные: **не** / **not**, `-`, `+`.
- Бинарные (внутри группы слева направо):
  - арифметика: `+` `-` `*` `/`
  - сравнение: `=` `<>` `>` `<` `>=` `<=`
  - логика: **и**/**или** (**and**/**or**)
- Конкатенация строк через `+` (в C — `str_concat`).

### Escape в строках

| Последовательность | Символ |
|--------------------|--------|
| `\n` | перевод строки |
| `\t` | табуляция |
| `\r` | возврат каретки |
| `\"` | кавычка |
| `\\` | обратный слэш |

### Сравнения → C

| `.alg` | C |
|--------|---|
| `=` | `==` |
| `<>` | `!=` |
| `>` `<` `>=` `<=` | те же |

## Встроенные

| RU | EN | Назначение |
|----|-----|------------|
| открыть | open | открыть файл (путь, режим) |
| закрыть | close | закрыть |
| конецфайла | eof | конец файла? |
| корень | sqrt | √ |
| модуль | abs | \|x\| |
| случ | rand | случайное [0,1) |
| случцел | randint | случайное целое в диапазоне |
| длина | len | длина |
| подстрока | substr | подстрока |
| вверх / вниз | upper / lower | регистр |
| вцел / ввещ / встроку | toint / toreal / tostr | преобразования |

**Режимы файла:** `чтение`/`read` → `r`, `запись`/`write` → `w`, `дозапись`/`append` → `a`.

Пути в `открыть` передаются в ОС **как есть** (без whitelist).

Все перечисленные встроенные транслируются в C (см. ограничения ниже).

## Типы (сводка)

| `.alg` | Семантика | В C |
|--------|-----------|-----|
| цел | целое | `int` |
| вещ | вещественное | `double` |
| лит | строка | `char*` (куча) |
| лог | логический | `bool` |
| таб *тип*[нач:кон] | массив | массив + offset |
| файл | дескриптор | `FILE*` |
| словарь | ключ-строка → число | `AlgDict` (в значениях — `double`) |
| запись / переч | пользовательские | `struct` / `enum` + MemberAccess |

### Числовая модель (интерпретатор)

- Арифметика через Python `float`.
- Деление `/` всегда вещественное (`5 / 2` → `2.5`).
- Присваивание дробного в `цел` без `вцел` — `AssignTypeWarning`.
- Формат вывода целых в интерпретаторе и в C может отличаться.

## Файловый I/O в C

`файл` → `FILE*`; `открыть`/`закрыть` → `fopen`/`fclose`; вывод/ввод — `fprintf` / `fscanf` / `fgets`. Режимные строки как выше. Пути не фильтруются.

## Интерпретатор vs C (ограничения 1.2.0)

| Тема | Интерпретатор | C |
|------|---------------|---|
| `длина(число)` / `len(число)` | длина `str(n)` | ожидается строка |
| `случ` / `случцел` | ГПСЧ Python | другой ГПСЧ C (`rand` и т.п.) — последовательности не совпадают |
| словарь | значения — числа Python | только `double` |
| `--keep-cyrillic` | — | кириллица в идентификаторах C |
| `--permissive` | — | неизвестные узлы → предупреждение, не жёсткая ошибка |
| Утечки строк/кучи | GC Python | возможны `MemoryLeakWarning` при генерации |

Сеть / host-API и VS Code packaging из `Gemini_reference` в SCHOOLALGOL не входят.

## Комментарии

Строковый комментарий: символ **`|`** (до конца строки). В плагине ALG — Toggle Comment по этому стилю.

## Отличия от «классического ШАЯ» (намеренно)

| Тема | Типичный ШАЯ | School Algol `.alg` |
|------|--------------|---------------------|
| Массив | часто `мас` | `таб тип имя[нач:кон]` |
| Циклы | варианты `для`/`пока` | `нц … кц` / `loop … eloop` |
| Модули | разное | `использовать` / `import` |
| Словарь | обычно нет | `словарь` / `dict` |
| Неравенство | разные формы | `<>` |
| Сравнения | не всегда `>=`/`<=` | часть языка |
| Файлы | учебные API | полный путь ОС |
| Среда | — | интерпретатор + C + Eclipse ALG |
