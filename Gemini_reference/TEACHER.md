# Gemini — кратко для преподавателя

## Что это

**Gemini** — интерпретатор и C-транспилятор учебного языка **`.alg`**.  
Язык **самостоятельный** (не классический ШАЯ): русские ключевые слова, свои конструкции (`таб`, `нц`/`кц`, `использовать`).

## Зачем в курсе

1. **Алгоритмы** — процедуры, циклы, ветвления, типы.
2. **Связь с C** — `python main.py prog.alg --transpile` → GCC → exe; комментарии `// alg: Имя` в `.c`.
3. **Реальные файлы** — без sandbox; можно читать конфиги и логи (с обсуждением этики и прав ОС).

## Быстрый старт урока

```bash
pip install -r requirements-dev.txt   # опционально, для тестов
python main.py examples/01_hello.alg
python main.py examples/04_loops.alg --verbose --trace
python main.py --repl
```

## Режимы отладки

- `--verbose` — этапы лексера/парсера/интерпретатора.
- `--trace` — каждый оператор и значения после `:=`.
- `--dump-ast` — дерево разбора для разбора на доске.

## Принципы (не нарушать в заданиях)

1. **Не требовать синтаксис ШАЯ** (`мас`, `раз`/`па` и т.д.).
2. **Не требовать sandbox** — полный доступ к ФС осознанный.
3. **Информативные ошибки** — поощрять чтение сообщения и `--verbose`.

## Проверка работ ученика

```bash
python main.py решение.alg
python launcher.py решение.alg --verbose   # полный цикл до exe
```
