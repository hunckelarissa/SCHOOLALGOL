# Грамматика и семантика языка .alg

Краткое описание конструкций **самостоятельного** учебного языка `.alg` (не классический ШАЯ).

## Принципы реализации

- **Самобытный синтаксис** — `таб`, `использовать`, `словарь`, `запись`, `переч` и др. — часть языка `.alg`, а не «отклонение от ШАЯ».
- **Информативность** — при запуске `python main.py файл.alg --verbose` в stderr выводятся этапы разбора и выполнения; `--trace` — пошаговая трассировка операторов.
- **Без sandbox** — пути в `открыть` и модулях `использовать` не фильтруются; допустимы абсолютные пути и выход за каталог исходника (`../lib/util.alg`).

## Точка входа

- Программа должна содержать процедуру с именем **основнаяпрограмма** или **mainprogram** (без параметров). Она вызывается при запуске.
- Имена процедур и переменных **регистронезависимы** (`ОсновнаяПрограмма` = `основнаяпрограмма`, `MainProgram` = `mainprogram`).

## Двуязычные ключевые слова (v1.1)

Русские и английские формы — **синонимы одного токена** (модель 1С). Парсер различает только `TokenType`, не язык написания. В одном файле допустимо смешение (`if` + `то` + `endif`).

| RU | EN | RU | EN |
|----|-----|----|-----|
| алг | proc | цел | int |
| нач | begin | вещ | real |
| кон | end | лог | bool |
| арг | arg | лит | str |
| рез | res | таб | tab |
| конст | const | файл | file |
| использовать | import | словарь | dict |
| ввод | input | запись | rec |
| вывод | output | переч | enum |
| если | if | да | true |
| то | then | нет | false |
| иначе | else | и | and |
| все | endif | или | or |
| нц | loop | не | not |
| кц | eloop | | |
| для | for | | |
| пока | while | | |
| от | from | | |
| до | to | | |

**Точка входа:** `основнаяпрограмма` / `mainprogram`.

**Встроенные (алиасы):** `открыть`/`open`, `закрыть`/`close`, `конецфайла`/`eof`, `корень`/`sqrt`, `модуль`/`abs`, `случ`/`rand`, `случцел`/`randint`, `длина`/`len`, `подстрока`/`substr`, `вверх`/`upper`, `вниз`/`lower`, `вцел`/`toint`, `ввещ`/`toreal`, `встроку`/`tostr`.

**Режимы файла:** `чтение`/`read`, `запись`/`write`, `дозапись`/`append`.

Пример (EN):

```alg
proc mainprogram
begin
  int x
  if x > 0 then
    output "ok"
  endif
end
```

Каталог примеров: `examples/en/`.

## Модули

- **использовать** `"файл.alg"` — подключает другой файл; объявления из него видны в текущем файле. Путь задаётся **относительно каталога текущего файла**; допускаются `..` и произвольная глубина (ограничений sandbox нет).

## Файловый доступ

- **открыть** ( *файловая_переменная* , *путь* , *режим* ) — *путь* передаётся в ОС **как есть**: относительный, абсолютный, системный (`C:\Windows\System32\drivers\etc\hosts`, `/etc/hosts` и т.д.).
- Режимы: «чтение» (`r`), «запись» (`w`), «дозапись» (`a`).
- Интерпретатор: `open(путь, режим)` в Python без whitelist.
- Транспилятор: `fopen(путь, режим)` в C без фильтрации.
- Ошибки открытия содержат исходный и абсолютный путь (см. `--verbose`).

## Объявления верхнего уровня

- **конст** *имя* = *выражение* — константа.
- **цел** | **вещ** | **лит** | **лог** | **таб** *тип* | **файл** | **словарь** | *имя_типа* — объявление переменных (одна или несколько через запятую); для массива: *имя* [ *нач* : *кон* ].
- **алг** *имя* [ ( **арг** ... ; **рез** ... ) ] [ *объявления* ] **нач** *тело* **кон** — процедура или функция (при наличии **рез** — функция). Перед **нач** допускаются только объявления (Pascal-style). В *теле* после **нач** объявления и операторы могут чередоваться (C-style).
- **запись** *имя* **нач** *поля* **кон** — тип-запись.
- **переч** *имя* ( *член1* , ... ) — перечисление.

## Операторы

- *переменная* **:=** *выражение* — присваивание (в т.ч. элемент массива, поле записи, ключ словаря).
- **вывод** [ *файл* , ] *выражение* [ , *выражение* ] ... [ : *ширина* [ : *точность* ] ] — вывод в консоль или в файл.
- **ввод** [ *файл* , ] *переменная* [ , *переменная* ] ... — ввод с консоли или из файла.
  - При **EOF** в файле в числовую переменную записывается `0.0` (контракт языка).
  - При `--verbose` интерпретатор сообщает в stderr: «достигнут конец файла, записано 0.0».
  - Рекомендуется проверять `конецфайла(f)` перед чтением.
- **если** *условие* **то** *операторы* [ **иначе** *операторы* ] **все**.
- **нц** **пока** *условие* *операторы* **кц** — цикл по условию.
- **нц** **для** *переменная* **от** *выражение* **до** *выражение* *операторы* **кц** — цикл по диапазону (включительно).
- *имя* ( [ *аргумент* [ , *аргумент* ] ... ] ) — вызов процедуры/функции.

### Цикл `нц для` и неявное объявление

Если переменная цикла не объявлена заранее, интерпретатор **неявно** создаёт её как **цел** в текущей области видимости и выдаёт предупреждение `ImplicitDeclareWarning`. Рекомендуется явно объявлять `цел i` перед циклом в учебных программах.

## Выражения

- Литералы: числа, строки в двойных кавычках, **да** / **нет**.
- Идентификаторы (переменные, константы), вызов функции, доступ к полю ( *выражение* . *поле* ), к элементу ( *выражение* [ *индекс* ] ).
- Унарные: **не** *выражение* , **-** *выражение* , **+** *выражение*.
- Бинарные (приоритет слева направо внутри группы):
  - Арифметика: **+** | **-** | **\*** | **/**
  - Сравнение: **=** | **<>** | **>** | **<** | **>=** | **<=**
  - Логика: **и** | **или**
- Строки можно конкатенировать оператором **+** (в интерпретаторе и в C — через `str_concat`).

### Операторы сравнения (расширение `.alg`)

| Оператор | Значение        | В C        |
|----------|-----------------|------------|
| `=`      | равно           | `==`       |
| `<>`     | не равно        | `!=`       |
| `>` `<`  | больше / меньше | как в C    |
| `>=` `<=`| больше/равно    | как в C    |

Это **намеренное** расширение языка `.alg`, а не синтаксис классического ШАЯ.

### Строковые литералы и escape

Внутри `"..."` поддерживаются escape-последовательности:

| Последовательность | Символ        |
|--------------------|---------------|
| `\n`               | перевод строки |
| `\t`               | табуляция     |
| `\"`               | кавычка       |
| `\\`               | обратный слэш |

Пример: `лит s; s := "строка\nвторая строка"`.

## Встроенные процедуры/функции

- **открыть** ( *файловая_переменная* , *путь* , *режим* ), **закрыть** ( *файловая_переменная* ).
- **корень** ( *число* ), **модуль** ( *число* ), **случ** ( ), **случцел** ( *мин* , *макс* ).
- **длина** ( *значение* ), **подстрока** ( *строка* , *начало* , *длина* ), **вверх** / **вниз** ( *строка* ).
- **вцел** / **ввещ** / **встроку** ( *значение* ).
- **конецфайла** ( *файловая_переменная* ) — признак достижения конца файла.

## Типы

| Тип `.alg` | Семантика | В C (транспилятор) |
|------------|-----------|---------------------|
| **цел**    | целое     | `int`               |
| **вещ**    | вещественное | `double`         |
| **лит**    | строка    | `char*` (куча, `strdup`/`free`) |
| **лог**    | логический | `bool`             |
| **таб** *тип* [ *нач* : *кон* ] | массив с индексами *нач*…*кон* | массив C с offset |
| **файл**   | файловый дескриптор | `FILE*`      |
| **словарь** | строковый ключ → число | `AlgDict` (linked list) |
| **запись** / **переч** | пользовательские типы | `struct` / `enum` |

## Числовая модель

- Внутри интерпретатора арифметика выполняется через **Python `float`** (`вещ` и результаты операций).
- Переменные **`цел`** хранят числовые значения; при присваивании дробного без `вцел(...)` выдаётся предупреждение `AssignTypeWarning`.
- Деление `/` всегда даёт вещественный результат (`5 / 2` → `2.5`).
- Вывод целых может отображаться как `42.0` в интерпретаторе; C-транспилятор форматирует иначе — см. паритет-тесты.
- Сравнения `=` и порядковые операторы работают для чисел; строки сравниваются лексикографически при необходимости.

При `--verbose` неявные преобразования (EOF в файл, неявное `цел` в `нц для`) логируются в stderr.

## EBNF (фрагменты грамматики)

Ниже — упрощённые правила языка `.alg` (расширенная Бэкуса — Наура). Регистр ключевых слов не важен.

```ebnf
program        = { top_decl } ;
top_decl       = use_stmt | record_decl | enum_decl | const_decl
               | proc_decl | func_decl ;
use_stmt       = "использовать" string_lit ;

proc_decl      = "алг" ID [ "(" param_list ")" ] { decl } "нач" body "кон" ;
func_decl      = "алг" ID [ "(" param_list ";" "рез" var_decl ")" ] { decl } "нач" body "кон" ;
body           = { decl | statement } ;
block          = { decl } "нач" body "кон" ;
decl           = const_decl | var_decl | array_decl | record_decl | enum_decl ;
const_decl     = "конст" ID "=" expr ;
var_decl       = type ID { "," ID } ;
array_decl     = "таб" type ID "[" expr ":" expr "]" ;

statement      = assign_stmt | print_stmt | input_stmt | if_stmt | loop_stmt
               | proc_call ;
assign_stmt    = lvalue ":=" expr ;
print_stmt     = "вывод" [ ID "," ] print_item { "," print_item } ;
print_item     = expr [ ":" expr [ ":" expr ] ] ;
input_stmt     = "ввод" [ ID "," ] ID { "," ID } ;
if_stmt        = "если" expr "то" { statement } [ "иначе" { statement } ] "все" ;
loop_stmt      = "нц" "для" ID "от" expr "до" expr { statement } "кц"
               | "нц" "пока" expr { statement } "кц" ;

expr           = logic_or ;
logic_or       = logic_and { "или" logic_and } ;
logic_and      = equality { "и" equality } ;
equality       = relation { ( "=" | "<>" ) relation } ;
relation       = additive { ( ">" | "<" | ">=" | "<=" ) additive } ;
additive       = mult { ( "+" | "-" ) mult } ;
mult           = unary { ( "*" | "/" ) unary } ;
unary          = [ "не" | "+" | "-" ] primary ;
primary        = literal | ID [ "(" arg_list ")" ] | "(" expr ")"
               | primary ( "." ID | "[" expr "]" ) ;
lvalue         = primary ;   (* в контексте присваивания *)

type           = "цел" | "вещ" | "лит" | "лог" | "файл" | "словарь" | "таб" type | ID ;
```

### Различение объявления и оператора в теле блока

В позиции `{ decl | statement }` парсер применяет однозначные правила (без эвристики «все объявления сначала»):

| Начало | Следующий токен | Разбор |
|--------|-----------------|--------|
| `цел`, `вещ`, `лит`, `лог`, `таб`, `файл`, `словарь`, `конст` | — | объявление |
| `запись`, `переч` | — | объявление типа |
| `ID` (имя типа) | `ID` (имя переменной) | объявление пользовательского типа |
| `ID` (переменная/вызов) | `:=`, `[`, `.`, `(` | оператор (присваивание или вызов) |
| `вывод`, `ввод`, `если`, `нц` | — | оператор |

Перед ключевым словом **нач** (между заголовком `алг` и телом) допускаются **только** объявления.

### Приоритет операторов (от слабого к сильному)

| Уровень | Операторы | Ассоциативность |
|---------|-----------|-----------------|
| 1 | `или` | слева направо |
| 2 | `и` | слева направо |
| 3 | `=` `<>` | слева направо |
| 4 | `>` `<` `>=` `<=` | слева направо |
| 5 | `+` `-` (бинарные) | слева направо |
| 6 | `*` `/` | слева направо |
| 7 | унарные `не`, `+`, `-` | справа |
| 8 | `.` `[]` `()` | слева |

Строковая конкатенация: `+`, если один из операндов — строка.

## Отличия от «классического ШАЯ» (намеренно)

Мы **намеренно** используем синтаксис `.alg`, а не приводим его к школьному ШАЯ:

| Тема | Классический ШАЯ (не мы) | Язык `.alg` (мы) |
|------|--------------------------|------------------|
| Массив | `мас`, `1:n` | `таб тип имя[нач:кон]` |
| Циклы | `для`, `пока`, `раз`/`па` | `нц для` / `нц пока` … `кц` |
| Модули | нет / разное | `использовать "файл.alg"` |
| Словарь | нет | `словарь` |
| Запись | `запись` (иногда иначе) | `запись` … `нач` … `кон` |
| Неравенство | различные варианты | `<>` |
| Сравнения | не всегда `>=` | `>=`, `<=` — часть языка |
| Файлы | ограниченные учебные API | полный путь, без sandbox |
| Транспилятор | редко в ШАЯ | C + GCC, паритет с интерпретатором |

Дополнительно:
- Оператор неравенства — **`<>`** (не «не» между операндами).
- Транспиляция в C с комментариями `// alg: ИмяПроцедуры`.
