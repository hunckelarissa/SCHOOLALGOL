# Участие в разработке проекта Gemini (язык `.alg`)

## Принципы (обязательны для всех изменений)

1. **Самобытность** — язык `.alg` не приводится к классическому ШАЯ; синтаксические отличия намеренны.
2. **Информативность** — ошибки и предупреждения подробные; новая логика должна поддерживать `--verbose`.
3. **Без sandbox** — **запрещено** добавлять ограничения доступа к файловой системе, whitelist путей, запрет `..`, chroot, виртуальную ФС или «безопасные» обёртки над `open`/`fopen`. Программы `.alg` выполняются с правами пользователя ОС.

При code review отклоняйте PR, нарушающие эти принципы.

## Web-sandbox и «детские» ограничения

Официальный путь проекта — **desktop CLI** с полным доступом к ОС (файлы, абсолютные пути, системные каталоги).

- **Не** принимается в основной репозиторий как целевое направление: web-sandbox с урезанным API, виртуальной ФС, whitelist путей или «безопасным режимом для детей».
- Отдельный экспериментальный форк или side-project допустим, но **не заменяет** интерпретатор и транспилятор Gemini.
- Предложения «добавить sandbox для безопасности» следует отклонять; см. раздел «Безопасность и доверие» в `README.md` и задачу P6-05 в `TODO.md`.

## Запуск тестов


## Стиль кода

- Сообщения пользователю — на русском.
- Диагностика (`verbose`, предупреждения) — в **stderr**, вывод программы (`вывод`) — в **stdout**.
- Минимальный дифф; следовать существующим соглашениям в каталоге.

## Чеклист узла AST

При добавлении нового узла в `ast_nodes.py` обновите **все** перечисленные места (см. также `visitors.AST_NODE_TYPES`):

| # | Компонент | Файл | Действие |
|---|-----------|------|----------|
| 1 | Лексер | `lexer.py`, `lang_tokens.py` | при необходимости — новые токены |
| 2 | Парсер | `parser.py` | разбор → узел AST |
| 3 | Семантика | `semantic_analyzer.py` | статические проверки |
| 4 | Интерпретатор | `interpreter.py` | `visit_<Узел>` |
| 5 | Транспилятор | `c_transpiler.py` | `visit_<Узел>` (или `--permissive` + предупреждение) |
| 6 | Тесты | `tests/` | unit и/или parity |
| 7 | Документация | `GRAMMAR.md` | EBNF и семантика |

Базовый класс обхода — `visitors.NodeVisitor` (общий для интерпретатора, транспилятора и анализатора).
