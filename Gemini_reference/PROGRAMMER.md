# Руководство программиста — язык .alg

Полный учебник по языку **.alg** и среде **Gemini** (интерпретатор + C-транспилятор).  
Версия среды: **1.1.0**.

Язык `.alg` — **самостоятельный** учебный алгоритмический язык. С **v1.1.0** ключевые слова доступны на **русском и английском** (синонимы, как в 1С). Это **не** классический ШАЯ: синтаксис (`таб`/`tab`, `использовать`/`import`, `словарь`/`dict`, `<>`, `нц для` / `loop for` …) намеренно отличается.

### Русский и английский синтаксис (v1.1)

Оба варианта равноправны; в одном файле можно смешивать формы. Полная таблица — в [GRAMMAR.md](GRAMMAR.md). Примеры EN: каталог `examples/en/`.

| RU | EN |
|----|-----|
| `алг основнаяпрограмма` | `proc mainprogram` |
| `нач` … `кон` | `begin` … `end` |
| `цел x` | `int x` |
| `если` … `то` … `все` | `if` … `then` … `endif` |
| `нц для i от 1 до 10` … `кц` | `loop for i from 1 to 10` … `eloop` |
| `вывод` / `ввод` | `output` / `input` |
| `открыть(f, path, "чтение")` | `open(f, path, "read")` |

## 1. Обзор среды

**Gemini** выполняет программы на `.alg` в два режима:

| Режим | Команда | Результат |
|-------|---------|-----------|
| Интерпретация | `python main.py файл.alg` | Немедленный запуск на Python |
| Транспиляция | `python main.py файл.alg --transpile` | Файл `файл.c` для GCC |

Пайплайн интерпретации:

```
исходник .alg → лексер → парсер → семантический анализ → выполнение
```

При `--verbose` каждый этап логируется в **stderr**; вывод программы (`вывод`) идёт в **stdout**.

Быстрый старт: **[QUICKSTART.md](QUICKSTART.md)**.

## 2. Структура программы

### Точка входа

Программа **обязана** содержать процедуру без параметров с именем **основнаяпрограмма**. При запуске вызывается именно она.

```alg
алг основнаяпрограмма
нач
  вывод "Старт"
кон
```

Имена **регистронезависимы**: `ОсновнаяПрограмма` и `основнаяпрограмма` — одно и то же.

### Блок `нач` … `кон`

Тело подпрограммы — между ключевыми словами **нач** и **кон**. Внутри допустимы:

- объявления переменных (`цел x`, `таб цел a[1:5]`, …);
- операторы (`вывод`, `:=`, циклы, …).

Объявления и операторы **могут чередоваться** (C-style):

```alg
алг основнаяпрограмма
нач
  цел x
  x := 1
  цел y
  y := x + 1
  вывод y
кон
```

Перед **нач** в заголовке `алг` (между именем и телом) допускаются **только объявления** (Pascal-style):

```alg
алг обработка
  цел счетчик
нач
  счетчик := 0
кон
```

### Объявления верхнего уровня

В одном файле `.alg` могут быть:

| Конструкция | Назначение |
|-------------|------------|
| `использовать "файл.alg"` | подключение модуля |
| `конст ИМЯ = выражение` | константа |
| `алг имя` … `кон` | процедура или функция |
| `запись Имя` … `кон` | тип-запись |
| `переч Имя(...)` | перечисление |

## 3. Типы и переменные

### Базовые типы

| Тип | Назначение | Пример объявления |
|-----|------------|-------------------|
| **цел** | целое число | `цел n, m` |
| **вещ** | дробное число | `вещ x` |
| **лит** | строка | `лит s` |
| **лог** | логическое (да/нет) | `лог флаг` |
| **файл** | файловый дескриптор | `файл f` |
| **словарь** | ассоциативный массив (ключ → число) | `словарь d` |

Несколько переменных одного типа через запятую:

```alg
цел a, b, c
```

### Присваивание

Оператор присваивания — **`:=`** (не `=`):

```alg
цел x
x := 42
```

### Константы

```alg
конст ПИ = 3.14159
конст ПРИВЕТ = "Здравствуйте"
```

Константу нельзя изменить; попытка присваивания — семантическая ошибка.

### Логические литералы

**да** и **нет** (регистр не важен).

### Числовая модель

- Арифметика в интерпретаторе выполняется через Python **float**.
- Деление `/` всегда вещественное: `5 / 2` → `2.5`.
- Присваивание дробного в **цел** без `вцел(...)` даёт предупреждение `AssignTypeWarning`.
- В консоли целые иногда отображаются как `42.0` — это особенность интерпретатора; в C формат иной (см. паритет-тесты).

## 4. Выражения и операторы

### Арифметика

`+` `-` `*` `/` — стандартные правила приоритета (`*` и `/` выше `+` и `-`).

Строки конкатенируются через `+`:

```alg
лит s
s := "Hello" + " " + "World"
```

### Сравнение

| Оператор | Значение |
|----------|----------|
| `=` | равно |
| `<>` | не равно |
| `>` `<` `>=` `<=` | порядок |

### Логика

Унарное **не**, бинарные **и**, **или**. Логические операции работают с значениями **да**/**нет** и в контексте условий.

### Скобки

`(выражение)` — группировка.

### Доступ к данным

```alg
массив[i]           | элемент массива
запись.поле         | поле записи
словарь["ключ"]     | значение словаря
```

### Escape в строках

Внутри `"..."`:

| Последовательность | Символ |
|--------------------|--------|
| `\n` | перевод строки |
| `\t` | табуляция |
| `\"` | кавычка |
| `\\` | обратный слэш |

## 5. Управление потоком

### Условие

```alg
если x > 0 то
  вывод "положительное"
иначе
  вывод "не положительное"
все
```

Ветка **иначе** необязательна.

### Цикл с условием

```alg
нц пока n > 0
  вывод n
  n := n - 1
кц
```

### Цикл со счётчиком

```alg
нц для i от 1 до 10
  вывод i
кц
```

Границы **включительны**: `от 1 до 3` выполнит `i = 1, 2, 3`.

Если `i` не объявлена, интерпретатор **неявно** создаёт `цел i` с предупреждением. В учебных программах лучше писать явно:

```alg
цел i
нц для i от 1 до 10
  ...
кц
```

### Ввод и вывод

**вывод** в консоль:

```alg
вывод "x = ", x
вывод x : 5          | ширина поля 5
вывод x : 8 : 2      | ширина 8, 2 знака после запятой (для вещ)
```

**ввод** с консоли:

```alg
цел n
ввод n
```

Несколько переменных: `ввод a, b, c`.

## 6. Подпрограммы

### Процедура

```alg
алг приветствие(арг лит имя)
нач
  вывод "Привет, ", имя
кон

алг основнаяпрограмма
нач
  приветствие("Анна")
кон
```

### Функция

Функция объявляется с **рез** — переменной результата:

```alg
алг квадрат(арг цел n; рез цел r)
нач
  r := n * n
кон

алг основнаяпрограмма
нач
  цел y
  y := квадрат(5)
  вывод y
кон
```

### Параметры

- **арг** — входные параметры: `арг цел a, цел b`
- **рез** — результат функции: `рез цел s`

Синтаксис со скобками:

```alg
алг Сумма(арг цел a, цел b; рез цел s)
нач
  s := a + b
кон
```

Вызов: `Сумма(3, 4)` или как оператор `приветствие("мир")`.

### Рекурсия

Допустима. При слишком глубокой рекурсии интерпретатор сообщает понятную ошибку с именем процедуры.

## 7. Массивы

Объявление:

```alg
таб цел a[1:5]    | индексы 1, 2, 3, 4, 5
таб вещ b[0:2]    | индексы 0, 1, 2
```

Присваивание и чтение:

```alg
a[3] := 100
вывод a[3]
```

Выход за границы — `SemanticError` с указанием допустимого диапазона.

Пример: `examples/05_arrays.alg`.

## 8. Записи и перечисления

### Запись

```alg
запись Точка
нач
  вещ x, y
кон

алг основнаяпрограмма
нач
  Точка p
  p.x := 1.5
  p.y := 2.5
  вывод p.x, " ", p.y
кон
```

### Перечисление

```alg
переч Цвет(красный, зеленый, синий)

алг основнаяпрограмма
нач
  Цвет c
  c := Цвет.зеленый
кон
```

Пример: `examples/09_records.alg`.

## 9. Словари

Тип **словарь** хранит пары «строковый ключ → число»:

```alg
словарь d
d["один"] := 1
d["два"] := 2
вывод d["один"]
```

Ключ в выражении — строковый литерал или переменная типа **лит**.

## 10. Модули

Подключение другого файла `.alg`:

```alg
использовать "../utils.alg"

алг основнаяпрограмма
нач
  вывод Факториал(5)
кон
```

Путь **относительно каталога текущего файла**; допустимы `..` и произвольная глубина. Ограничений sandbox нет.

Все объявления из модуля (процедуры, константы, типы) становятся видимы в текущем файле. Циклический импорт обнаруживается с цепочкой файлов в сообщении об ошибке.

Пример: `examples/10_module.alg` (модуль `utils.alg` в корне проекта).

## 11. Файловый ввод-вывод

### Открытие и закрытие

```alg
файл f
открыть(f, "data.txt", "запись")
вывод f, "строка в файл"
закрыть(f)
```

Режимы: **"чтение"**, **"запись"**, **"дозапись"**.

### Вывод в файл

```alg
вывод f, "текст", x
```

Первый аргумент после `вывод` — файловая переменная.

### Ввод из файла

```alg
ввод f, x, y
```

### Конец файла

```alg
если не конецфайла(f) то
  ввод f, x
все
```

При **EOF** в `ввод` из файла в переменную записывается **0.0** (контракт языка). При `--verbose` интерпретатор сообщает об этом в stderr.

### Пути без ограничений

Путь передаётся в ОС **как есть** — абсолютный, относительный, системный (`hosts`, логи). Ответственность за выбор пути — на авторе программы. См. `examples/06_files.alg`, `examples/08_hosts.alg`.

## 12. Встроенные функции

| Имя | Аргументы | Назначение |
|-----|-----------|------------|
| **открыть** | файл, путь, режим | открыть файл |
| **закрыть** | файл | закрыть файл |
| **конецфайла** | файл | конец файла? (да/нет) |
| **корень** | число | квадратный корень |
| **модуль** | число | абсолютное значение |
| **случ** | — | случайное вещ [0, 1) |
| **случцел** | мин, макс | случайное цел в диапазоне |
| **длина** | строка | длина строки |
| **подстрока** | строка, начало, длина | фрагмент строки |
| **вверх** / **вниз** | строка | регистр |
| **вцел** / **ввещ** / **встроку** | значение | преобразование типа |

Неверное число аргументов — семантическая ошибка с ожидаемыми именами параметров.

## 13. Комментарии и стиль

Комментарий от **`|`** до конца строки:

```alg
| это комментарий
цел x    | и здесь
```

Рекомендации:

- одна главная процедура `основнаяпрограмма` на учебный файл;
- осмысленные имена на русском или латинице (регистр не важен);
- для циклов `нц для` объявляйте счётчик явно;
- файловые пути проверяйте осмысленно — среда доверяет программе полностью.

## 14. Отладка и диагностика

### Флаги CLI

| Флаг | Назначение |
|------|------------|
| `--verbose` | этапы лексера, парсера, семантики, интерпретатора |
| `--trace` | каждый оператор и присваивание `:=` |
| `--dump-ast` | дерево разбора вместо выполнения |
| `--warnings-as-errors` | предупреждения → код выхода 3 |
| `--repl` | интерактивный ввод |

Пример:

```bash
python main.py program.alg --verbose --trace
```

### Сообщения об ошибках

Ошибки содержат строку, столбец, фрагмент кода с `^`, подсказку и (при вложенных вызовах) трассировку процедур.

Неизвестный идентификатор — подсказка «возможно, имелось в виду …» (поиск похожих имён в области видимости).

### REPL

```bash
python main.py --repl
```

Удобен для коротких экспериментов. Команды: `выход`, `.reset`, `.история`.

### AST

```bash
python main.py program.alg --dump-ast
python main.py program.alg --dump-ast --dump-ast-format json
```

## 15. Транспиляция в C

### Генерация

```bash
python main.py program.alg --transpile
python main.py program.alg --transpile --verbose
python main.py program.alg --transpile --keep-cyrillic
```

Флаги:

- **--keep-cyrillic** — кириллица в идентификаторах C (UTF-8);
- **--permissive** — неподдерживаемые узлы → предупреждение и заглушка в C.

### Соответствие типов

| .alg | C |
|------|---|
| цел | `int` |
| вещ | `double` |
| лит | `char*` (куча) |
| лог | `bool` |
| файл | `FILE*` |
| таб | массив с offset |
| запись | `struct` |
| переч | `enum` |

Над функциями в `.c` — комментарии `// alg: ИмяПроцедуры`.

### Память и строки

Строковая конкатенация в C использует `str_concat` / `strdup` / `free`. При **вложенной** конкатенации в одном выражении транспилятор выдаёт `MemoryLeakWarning` — разбейте на промежуточные присваивания в переменные **лит**.

### Полный цикл

```bash
python launcher.py examples/01_hello.alg --verbose
```

Паритет интерпретатор ↔ C проверяется тестами в `tests/programs/` и `tests/test_parity.py`.

## 16. Принципы и ограничения

### Три принципа языка

1. **Самобытность** — не стремимся к совместимости с классическим ШАЯ.
2. **Информативность** — подробные ошибки, verbose, предупреждения.
3. **Без sandbox** — полный доступ к файловой системе; пути не фильтруются.

### Подсветка синтаксиса

TextMate-грамматика для VS Code / Cursor: каталог `editor/alg/` (локальная установка).
