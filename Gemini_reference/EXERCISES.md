# Задания по языку .alg

Уровни: **Н** — начальный, **С** — средний, **П** — продвинутый.  
Решения проверяйте: `python main.py файл.alg` или `python main.py --repl`.

---

## Уровень Н (начальный)

### Н-1. Приветствие
Напишите программу, которая выводит ваше имя и класс.

### Н-2. Сумма двух чисел
Объявите `цел a, b`, присвойте значения, выведите сумму.

### Н-3. Чётность
По числу `n` выведите «чётное» или «нечётное» (оператор `<>` пригодится).

### Н-4. Таблица умножения
Цикл `нц для` от 1 до 10: выведите строку `i * 5 = ...`.

### Н-5. Строка с переводом строки
Создайте `лит s` со значением `"строка1\nстрока2"` и выведите (проверьте escape `\n`).

---

## Уровень С (средний)

### С-1. Факториал
Функция `алг Факториал(арг цел n; рез цел)` — рекурсия или цикл.

### С-2. Массив и среднее
`таб вещ data[1:5]`, заполните в цикле, выведите среднее арифметическое.

### С-3. Запись «Точка»
```alg
запись Точка
нач
  вещ x, y
кон
```
Создайте переменную, присвойте полям значения, выведите координаты.

### С-4. Файл журнала
Запишите в `journal.txt` три строки с датой/событием, затем прочитайте и выведите.

### С-5. Словарь частот
`словарь d`, для строки `"abacaba"` посчитайте вхождения символов (ключ — один символ).

### С-6. Модуль
Вынесите функцию в отдельный `.alg` и подключите через `использовать "модуль.alg"`.

---

## Уровень П (продвинутый)

### П-1. Чтение конфига с диска
Прочитайте **любой** текстовый файл по абсолютному пути (например, первые 10 строк `hosts` или учебного `.ini`).  
**Ответственность:** только файлы, к которым у вас есть право чтения.

### П-2. Паритет с C
Напишите программу с циклами и форматом `вывод x:8:2`, проверьте:
```bash
python main.py prog.alg
python main.py prog.alg --transpile
gcc prog.c -o prog -lm && ./prog
```

### П-3. Пузырьковая сортировка
`таб цел a[1:n]`, отсортируйте вложенными циклами `нц`.

### П-4. Транспиляция с кириллицей
Процедура с русским именем `алг Сумма`, транспиляция с `--keep-cyrillic`, сравните с `.c`.

### П-5. Отладка AST
Для своей программы выполните `python main.py prog.alg --dump-ast` и найдите узлы `ForNode`, `IfNode`.

## Критерии оценки (для преподавателя)

| Критерий | Баллы |
|----------|-------|
| Программа компилируется (парсер без ошибок) | 2 |
| Корректный результат на тестовых данных | 3 |
| Читаемые имена, комментарии `\|` | 1 |
| Обработка граничных случаев (пустой файл, n=0) | 2 |
| Для П-1: осознанный выбор пути, без sandbox-ограничений | 2 |
