## In Eclipse

1. **ALG → Project / Docs → Import Track as Project** — linked project `shaya-track`.
2. Or open files from Explorer / File → Open.
3. **ALG → Run** / **Check** / **Step Debug**.

See [GRAMMAR.md](../../GRAMMAR.md) / [GRAMMAR.ru.md](../../GRAMMAR.ru.md) and [IDE_SETUP.md](../../IDE_SETUP.md).

Sync into dropins:

```powershell
.\install_dropins.ps1 -Examples
```
