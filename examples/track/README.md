# Учебный трек SCHOOLALGOL

Краткий маршрут по примерам `.alg` (русские ключевые слова) и параллельным EN-файлам.

## Порядок уроков (RU)

| № | Файл | Тема |
|---|------|------|
| 1 | [`../01_hello.alg`](../01_hello.alg) | первая программа |
| 2 | [`../02_variables.alg`](../02_variables.alg) | переменные, арифметика |
| 3 | [`../03_conditions.alg`](../03_conditions.alg) | условия, `>=` / `<=` / `<>` |
| 4 | [`../04_loops.alg`](../04_loops.alg) | циклы `нц` / `кц` (см. также `шаг`, `выход`, `продолжить` в [GRAMMAR.md](../../GRAMMAR.md)) |
| 5 | [`../05_arrays.alg`](../05_arrays.alg) | массивы `таб` |
| 6 | [`../06_files.alg`](../06_files.alg) | файлы |
| 7 | [`../07_strings.alg`](../07_strings.alg) | строки и escape |
| 9 | [`../09_records.alg`](../09_records.alg) | записи |
| 10 | [`../10_module.alg`](../10_module.alg) | модули |

Те же темы на английских ключевых словах: каталог [`../en/`](../en/).

## В Eclipse

1. **ALG → Project / Docs → Import Track as Project** — связанный проект `shaya-track`.
2. Или откройте файлы из Explorer / File → Open.
3. **ALG → Run** / **Check** / **Step Debug**.

См. также [GRAMMAR.md](../../GRAMMAR.md) и [IDE_SETUP.md](../../IDE_SETUP.md) в корне репозитория.

Синхронизация в dropins:

```powershell
.\install_dropins.ps1 -Examples
```
